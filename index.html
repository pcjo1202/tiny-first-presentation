소프트웨어 설계

요소들을 유익하게
관계 맺는 일

키워드의미예시
요소경계가 있는 구성 단위함수 → 객체 → 모듈 → 시스템
관계요소들 사이의 연결호출, 발행, 대기, 참조
유익하게관계에서 파생되는 이점함수 A가 B 덕분에 더 단순해지는 것
설계의 세 가지 행위 — Box.area() 예시

새 요소를 만들고, 관계를 조정하고, 이점을 얻는다

Before
caller()
    return box.width() * box.height()

caller가 box의 내부를 알아야 한다

After
caller()
    return box.area()

Box >> area()
    return width() * height()

caller가 단순해진 이점

시간 가치 vs 옵션 가치

⏰

시간 가치

오늘의 1달러 > 내일의 1달러
빨리 벌고, 늦게 쓰자

VS
🎰

옵션 가치

불확실성 속에서
옵션 > 물건 자체

시간 가치

오늘의 1달러 > 내일의 1달러

  • 지금 사용할 수 없다
  • 지금 투자할 수 없다 — 복리 기회 상실
  • 약속이 지켜지지 않을 가능성이 있다

시간 가치만 보면 → 코드 정리는 나중에!
먼저 벌고, 나중에 쓰자

시간 가치 — 구체적 예시

같은 금액이라도 시점에 따라 가치가 다르다

📉

A안 — 미래에 받기

오늘 1천만 투자
→ 10년 후 2천만 수령

⚠ 10년 내내 긴장
⚠ 10년 뒤 그 회사가 없을 수도
⚠ 1천만을 10년간 다른 데 못 씀

VS
📈

B안 — 지금 받기

오늘 1천2백만 수령
→ 10년 후 1천만 지불

✅ 첫날부터 2백만 확보
✅ 나머지를 투자하여 복리 수익
✅ 10년 후에도 여유 있음

💡 소프트웨어도 마찬가지 — 숫자를 볼 때 항상: "언제 발생하는가? 얼마나 확실한가?"

옵션 가치 — 감자 콜 옵션

물건을 살까, 살 권리를 살까?

🥔 감자를 산다

오늘 1달러로 감자를 산다
→ 감자를 소유한다

확정된 소유
감자가 필요 없으면 손해

🎫 콜 옵션을 산다

"내일 1달러에 살 권리"를
오늘 적은 돈(예: 10원)에 산다

필요하면 사고, 아니면 10원만 손해
불확실할 때 최선의 전략

💻 소프트웨어에 대입하면:
다음 동작 변경 = 감자 (실제로 필요한 가치)
오늘의 설계 = 옵션 프리미엄 (미래 선택지를 만드는 적은 비용)

비용의 정체를
밝히다

결합도

"한 요소를 변경하려면
다른 요소도 변경해야 한다"

coupled(E1, E2, Δ) ≡ ΔE1 ⇒ ΔE2

그냥 "결합되어 있다"는 부족합니다
"어떤 변경에 대해" 결합되어 있는가를 명시해야 합니다

결합도가 악몽인 이유

1:N + 연쇄작용 = 멱법칙

📦
요소 A 변경
→
📦📦📦
B, C, D 변경
일대다 (1:N)
→
💣
E, F, G... 연쇄
연쇄작용

소수의 큰 변경이 전체 비용 대부분을 차지한다

실제 사례

보이지 않는 결합도

⚠️ 페이스북 사례

두 서비스가 같은 물리적 랙을 공유
→ 한 서비스가 백업 정책을 변경
→ 네트워크 스위치 포화
→ 두 번째 서비스 장애

두 팀은 서로의 존재조차 몰랐지만, 결합되어 있었다

결합도는 왜 존재하는가

결합도 줄이기 예시 — 통신 프로토콜

포맷을 도입하면 결합도가 줄어든다. 하지만 사라지진 않는다

Before — 직접 결합
Sender >> send()
    writeField1()
    writeField2()

Receiver >> receive()
    readField1()
    readField2()
After — 포맷 도입
format = [
  {field:"1", type:"integer"},
  {field:"2", type:"string"}
]
Sender >> send()
    writeFields(format)
Receiver >> receive()
    readFields(format)

가장 중요한 통찰

한 종류의 결합도 ↓
→ 다른 종류의 결합도 ↑

선택지불하는 비용얻는 이점
결합도 유지변경 시 연쇄 비용당장의 설계 비용 절감
결합도 제거설계 비용 (지금 투자)미래 변경 비용 절감 + 옵션

모든 결합을 없앨 수 없다 — 적정선을 찾아야 한다

응집도

결합된 요소를 한곳에 모으기

하위 모듈로 추출

도우미 함수 추출

방법 2

다른 곳으로 이동
